# Płynność – trening płynności mowy

Osobista aplikacja (statyczny HTML, bez frameworka) do codziennego 15-minutowego treningu płynności mowy dla dorosłego z jąkaniem: 12-tygodniowy program oparty na badaniach, ocena nagrań przez Claude, mapa postępu w stylu Duolingo.

To repo jest jednocześnie vaultem Obsidiana (otwórz katalog repo jako vault) i kodem aplikacji.

- Apka (live): https://claude.ai/artifact/EUANdz59Df6hkaxVUsHR5P
- Start: `00 Start/Start.md` → `wiki/decyzje/Decyzje do podjęcia.md` → `wiki/produkt/Backlog.md`
- Dla agenta: `CLAUDE.md`
- Testy: `node test/run.js && node test/round2.js` (Node 22+, Playwright z Chromium)
